# Thinking about Proof: interactive student edition

The built web pages of an interactive edition of the booklet *Thinking about Proof*, for
students moving from A-level to university proof-based mathematics.

Read it at https://bmjdavies.github.io/TAP-interactive/

This repository holds only the generated website. The computer-marked questions are
[STACK](https://stack-assessment.org/) questions, rendered and marked by a STACK server.
