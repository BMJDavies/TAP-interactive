Example 7.3.3 No integer solutions.

Prove that the equation \(x^3 = 99x + 1\) has no integer solutions.
🔗
Solution.
Assume, for contradiction, that the equation has an integer solution, and call it \(k\text{.}\) Then \(k^3 = 99k + 1\text{.}\) Now \(k\) is either even or odd.
🔗
If \(k\) is even, then \(k^3\) is even and \(99k + 1\) is odd, which is not possible.
🔗
If \(k\) is odd, then \(k^3\) is odd and \(99k + 1\) is even, which is not possible either.
🔗
In both cases we have a contradiction. So the assumption is false, and the equation has no integer solutions.
