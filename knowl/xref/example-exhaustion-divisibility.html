Example 4.3.3 Using remainders.

Prove that if \(m\) is an integer that is not a multiple of 3, then \(m^2 - 1\) is a multiple of 3.
🔗
Solution.
Splitting by the remainder on division by 3, every integer is one of the following:
  1. a multiple of 3;
    🔗
    🔗
  2. 1 more than a multiple of 3;
    🔗
    🔗
  3. 2 more than a multiple of 3.
    🔗
    🔗
🔗
Case (i) is ruled out by the hypothesis, so we need only check cases (ii) and (iii). In both we use the difference of two squares, \(m^2 - 1 = (m - 1)(m + 1)\text{.}\)
🔗
Case (ii): \(m\) is 1 more than a multiple of 3, so \(m = 3k + 1\) for some integer \(k\text{.}\) Then
\begin{align*} m^2 - 1 \amp = (3k + 1)^2 - 1\\ \amp = (3k + 1 - 1)(3k + 1 + 1)\\ \amp = 3k(3k + 2), \end{align*}
which is a multiple of 3.
🔗
Case (iii): \(m\) is 2 more than a multiple of 3, so \(m = 3k + 2\) for some integer \(k\text{.}\) Then
\begin{align*} m^2 - 1 \amp = (3k + 2)^2 - 1\\ \amp = (3k + 2 - 1)(3k + 2 + 1)\\ \amp = (3k + 1)(3k + 3)\\ \amp = 3(3k + 1)(k + 1), \end{align*}
which is a multiple of 3.
🔗
Every case allowed by the hypothesis has been checked, so the statement is proved.
