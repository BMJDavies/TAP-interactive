Example 2.1.2.

By finding a suitable counterexample, prove that this conjecture is false: for all real numbers \(a\) and \(b\text{,}\)
\begin{equation*} a^3 + b^3 = (a + b)^3. \end{equation*}
🔗
Solution.
When \(a = 4\) and \(b = 1\text{,}\)
\begin{align*} a^3 + b^3 \amp = 4^3 + 1^3 = 64 + 1 = 65,\\ (a + b)^3 \amp = (4 + 1)^3 = 5^3 = 125. \end{align*}
Since \(65 \neq 125\text{,}\) this counterexample shows that the conjecture is false.
