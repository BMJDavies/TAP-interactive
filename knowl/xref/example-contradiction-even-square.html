Example 7.4.1 If \(a^2\) is even, then \(a\) is even.

Let \(a\) be an integer. Prove that if \(a^2\) is even, then \(a\) is even.
🔗
Solution.
Suppose, for contradiction, that \(a^2\) is even and \(a\) is not even. Then \(a\) is odd, so \(a = 2c + 1\) for some integer \(c\text{.}\) Then
\begin{gather*} a^2 = (2c + 1)^2 = 4c^2 + 4c + 1 = 2(2c^2 + 2c) + 1, \end{gather*}
so \(a^2\) is odd. So \(a^2\) is even and \(a^2\) is not even, a contradiction. So if \(a^2\) is even, then \(a\) is even.
