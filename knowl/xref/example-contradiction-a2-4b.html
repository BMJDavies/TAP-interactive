Example 7.4.3 \(a^2 - 4b\) is never 2.

Prove that if \(a\) and \(b\) are integers, then \(a^2 - 4b \neq 2\text{.}\)
🔗
Solution.
Suppose, for contradiction, that this statement is false. In other words, there exist integers \(a\) and \(b\) for which “\(a^2 - 4b \neq 2\)” is false. Or again, worded differently: there exist integers \(a\) and \(b\) for which \(a^2 - 4b = 2\text{.}\)
🔗
From this equation, \(a^2 = 4b + 2 = 2(2b + 1)\text{,}\) so \(a^2\) is even. Since \(a^2\) is even, \(a\) is even, by Example 7.4.1. So \(a = 2c\) for some integer \(c\text{.}\)
🔗
Substituting \(a = 2c\) into \(a^2 - 4b = 2\) gives \((2c)^2 - 4b = 2\text{,}\) so \(4c^2 - 4b = 2\text{.}\) Dividing by 2 gives \(2c^2 - 2b = 1\text{,}\) so \(1 = 2(c^2 - b)\text{.}\) Since \(c^2 - b\) is an integer, 1 is even. This is a contradiction.
🔗
So the assumption that the statement is false is itself false, and the statement is true.
