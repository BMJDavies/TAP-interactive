Example 7.2.1 Infinitely many primes.

Prove that there are infinitely many prime numbers.
🔗
Solution.
Assume, for contradiction, that there are only finitely many primes. List them all in increasing order, \(p_1 = 2\text{,}\) \(p_2 = 3\text{,}\) \(p_3 = 5\text{,}\) \(p_4 = 7\text{,}\) \(\ldots\text{,}\) \(p_n\text{,}\) so that \(p_n\) is the largest prime. Now consider the number
\begin{gather*} N = p_1 p_2 p_3 \cdots p_n + 1, \end{gather*}
one more than the product of all the primes. Dividing \(N\) by any of \(p_1, p_2, \ldots, p_n\) leaves remainder 1, so none of them divides \(N\text{.}\) But \(N\) is greater than 1, so \(N\) is either prime or divisible by a prime. Either way, some prime divides \(N\text{,}\) and it is not in our list, so it is larger than \(p_n\text{.}\) This contradicts the assumption that \(p_n\) is the largest prime. So the assumption is false, and there are infinitely many primes.
