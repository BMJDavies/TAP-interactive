Example 7.4.4 An inequality for every \(x\).

Prove that \(\sin x + \cos x \geq 1\) for every real number \(x\) with \(0 \leq x \leq \dfrac{\pi}{2}\text{.}\)
🔗
Solution.
Suppose, for contradiction, that the statement is false. Then there is at least one \(x\) with \(0 \leq x \leq \dfrac{\pi}{2}\) for which \(\sin x + \cos x \lt 1\text{.}\)
🔗
For \(0 \leq x \leq \dfrac{\pi}{2}\text{,}\) neither \(\sin x\) nor \(\cos x\) is negative, so \(0 \leq \sin x + \cos x \lt 1\text{.}\) Squaring non-negative numbers keeps their order, so
\begin{align*} 0^2 \amp \leq (\sin x + \cos x)^2 \lt 1^2,\\ 0 \amp \leq \sin^2 x + 2\sin x \cos x + \cos^2 x \lt 1. \end{align*}
Since \(\sin^2 x + \cos^2 x = 1\text{,}\) this gives
\begin{gather*} 0 \leq 1 + 2\sin x \cos x \lt 1, \end{gather*}
and so \(2\sin x \cos x \lt 0\text{.}\) But this contradicts the fact that neither \(\sin x\) nor \(\cos x\) is negative. So the statement is true.
