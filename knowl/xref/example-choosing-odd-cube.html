Example 8.1.3 An odd cube plus one.

Prove that if \(n\) is an odd integer, then \(n^3 + 1\) is an even integer.
🔗
Solution.
Does the statement seem reasonable? Try a few odd values of \(n\) first: \(n = 1\) gives \(1^3 + 1 = 2\text{,}\) \(n = 3\) gives 28 and \(n = 5\) gives 126, all even. So it looks true, and we look for a proof.
🔗
Start from what is given: \(n\) is odd, so \(n = 2p + 1\) for some integer \(p\text{.}\) Then
\begin{gather*} n^3 + 1 = (2p + 1)^3 + 1 = (2p)^3 + 1^3 + 3(2p)(1)(2p + 1) + 1 \end{gather*}
(using \((a + b)^3 = a^3 + b^3 + 3ab(a + b)\)). This looks messy, but look at it term by term. The first term is even: \((2p)^3 = 2(4p^3)\text{.}\) The second term, \(1^3 = 1\text{,}\) is odd. The third term, \(6p(2p + 1)\text{,}\) is even. The last term, 1, is odd. Two odd numbers add up to an even number, and adding even numbers keeps it even, so \(n^3 + 1\) is even.
🔗
In one line: \(n^3 + 1 = 8p^3 + 12p^2 + 6p + 2 = 2(4p^3 + 6p^2 + 3p + 1)\text{,}\) and \(4p^3 + 6p^2 + 3p + 1\) is an integer.
